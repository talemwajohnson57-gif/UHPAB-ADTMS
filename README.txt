UHPAB-ADTMS — BIT 2102 Examination Prototype

This prototype is based on the UHPAB Awards Department case used in the accompanying coursework report and the uploaded BIT 2102 examination instructions.

RUN ON YOUR LENOVO LAPTOP
1. Download and extract UHPAB_ADTMS_Exam_Prototype.zip.
2. Open the extracted folder.
3. Double-click index.html.
4. It opens in Microsoft Edge, Google Chrome, Firefox, or another modern browser.
5. Choose a demonstration role and enter the system. No password is configured.

EXAM-RELEVANT FEATURES
- Multiple functional areas: Awards, IT, Assessment, Production, Schools, Management and ICT administration.
- User categories: students, operational staff, supervisors, senior management, school representatives and system administrators.
- Operational information: request registration, verification, case status, production and dispatch.
- Tactical information: pending workload, departmental confirmations, request categories and delivery acknowledgement.
- Strategic information: aggregated indicators for management review.
- Central request register with generated tracking numbers.
- Verification and investigation fields for IT and Assessment.
- Production and quality-check fields.
- School Document Delivery Register and separate acknowledgement of receipt.
- Student tracking using tracking number plus registration reference.
- Reports and printing.
- Local browser storage.

DEMONSTRATION LOGIN
No password is required. Select any demonstration role on the opening screen.

IMPORTANT LIMITATIONS
This is an academic front-end prototype. It uses fictional sample records and browser local storage.
Role selection is for demonstration and is not secure server-side authorisation. It is not connected to UHPAB official databases and must not be used for real student records, official payments, or official decisions.
A live system would require UHPAB approval, secure server-side authentication and authorisation, a relational database, encryption, audit logs, backups, retention rules and ICT/data-protection review.

SUGGESTED DEMONSTRATION
1. Register a correction request.
2. Open the case and record IT and Assessment confirmations.
3. Update its production status and quality-check result.
4. Mark it Ready for dispatch.
5. Record dispatch to a fictional school.
6. Acknowledge receipt with an evidence reference.
7. Open MIS Reports and explain the operational, tactical and strategic indicators.
8. Use Student Tracking with the tracking number and registration reference.
